# 演示视频脚本与分镜（目标 150 秒，上限 180 秒）

> 旁白里的数字取自快照 v20261017-200627（由 `cpo_universe.json` 读出）。重新跑管道后数字可能变化，以录制时页面上显示的为准。

录制前准备：浏览器 1440×900，深色主题，打开线上地址（或本地 `node web/scripts/pages-dev.mjs`）。
建议用 OBS 录屏加配音；所有画面都是真实页面，不剪入任何手动修改过的数据。
旁白控制在约 380 字（中文语速约每秒 2.6 字）。

## 录制要点
- 第 3 步一定要真的点开到 call_id，这是“可追溯”最直观的证明。
- 第 7 步的问答要现场提问（线上调用 DeepSeek 约需 3 秒），可以先预热一次。
- 如果线上问答不可用（没有设置 secret），第 7 步改为展示拒答类问题（这类问题不调用 LLM），并在旁白里说明。
- 超时的话，优先删第 8 步，其次压缩第 5 步。
