# 方案提案（v0，待确认）

产品暂名 **OptiChain · AI 算力光互联产业研究台**。目标用户：卖方和买方研究员、产业投资者。它解决三个问题：①某家公司在光互联链上到底做哪个环节，证据是什么；②“CPO 概念股”里谁真有收入，谁只是表态；③海外 Capex、政策、汇率的变化会沿链条传到谁的哪个财务指标上。所有数据非实时，都标注截止日。

## 1. 产业链分层口径

口径来源：iFinD 主营构成（按产品）＞ 年报和投资者关系记录原文 ＞ 申万三级 / 中信行业 ＞ iFinD 概念。**我们的调整**：按“收入来自什么产品”归属，不按行业代码。比如中际旭创在申万口径下是“通信网络设备及器件”，在本产品里按 97.95% 的光模块收入归入中游。

| 层级 | 环节 → 子环节 | 样本公司（A 股 ↔ 海外） |
|---|---|---|
| 上游 | 光芯片（EML / DFB / CW / VCSEL / 探测器） | 源杰科技、长光华芯、仕佳光子 ↔ Lumentum、Coherent |
| 上游 | 电芯片（DSP / Driver / TIA / 电源） | （A 股几乎空白）↔ Broadcom、Marvell、Credo |
| 上游 | 光器件 / 无源 / 光引擎组件 | 天孚通信、光库科技、太辰光 ↔ Fabrinet（代工）、Coherent |
| 上游 | 封装材料与基板（陶瓷外壳 / PCB） | 中瓷电子、沪电股份 ↔ — |
| 上游 | 设备（耦合 / 测试） | 博杰股份 ↔ — |
| 中游 | 可插拔光模块（400G / 800G / 1.6T）、LPO | 中际旭创、新易盛、光迅科技、华工科技、剑桥科技 ↔ Coherent、AAOI、Fabrinet |
| 中游 | CPO / NPO 光引擎 | 同上（大多处于研发或送样阶段）↔ Broadcom |
| 下游 | 交换机 / AI 服务器 | 紫光股份、工业富联 ↔ NVIDIA |
| 下游 | 云厂商（需求方） | — ↔ Microsoft、Alphabet、Amazon、Meta |

一家公司可以挂在多个环节下。主次归属规则：分产品收入占比最高的为主，其他 ≥10% 的为次；没有分产品数据的公司按文本证据归属，并标“归属依据为文本”。全集约 **25 家 A 股 + 12 家海外公司**，另从 CPO 概念 225 只成分股里取约 15 只作为“概念可信度”样本。

## 2. 可信度分级（规则函数裁定，LLM 只给建议）

| 等级 | 规则（按顺序，命中即停） |
|---|---|
| **E 否认** | 公司澄清公告或 IR 回复中明确否认 |
| **A 有收入** | 分产品项目名称命中该概念的产品词表，且收入 > 0。输出金额、占比、报告期 |
| **B 订单 / 量产** | 正式文件（定期报告、IR 记录、公告）里有“批量出货 / 量产 / 订单 / 客户认证 / 募投扩产”等表述 |
| **C 研发 / 送样** | 正式文件中是“研发 / 送样 / 小批量 / 开发中”；或互动易里自称量产、但没有正式文件佐证（**互动易最高给 C**） |
| **D 仅表态** | 只有互动易或业绩说明会里的“关注 / 布局 / 可应用于”这类表述 |
| **E 无证据** | 按固定检索范围（公告、资讯、概念解析，近 24 个月）都没检索到，记录检索的 query 和时间 |

附加规则：①证据超过 24 个月的降一级，标“陈旧”；②证据冲突（如资讯说有收入、公告否认）时保留双方，按低的一级展示；③LLM 抽取时必须带原文片段，代码校验片段**逐字存在**于 iFinD 返回文本中，不存在的丢弃并记日志；④LLM 建议的等级与规则结果不一致时，标“待人工复核”。

## 3. 数据模型（快照 JSON，带版本号）

`ApiCall`（id、服务、工具、参数、调用时间、耗时、原始返回哈希）→ `Evidence`（来源类型、来源名称、日期、片段或字段名、URL 或巨潮检索链接、api_call_id）→ `Metric`（公司、字段、财年标签、**真实起止日**、值、单位、币种、api_call_id）。在此之上：`Membership`（公司—环节—主/次—占比—evidence_ids）、`ConceptLink`（公司—概念—等级—规则轨迹—LLM 建议—是否复核）、`ComparablePair`（可比维度[]、不可比维度[]、口径调整步骤[]）、`TransmissionEdge`（起点 → 终点、方向 ±、机制、时滞、置信度、evidence_ids）、`Snapshot`（版本、生成时间、数据截止日、与上一版的 diff）。

## 4. 跨市场可比与传导

- **可比**：每组可比都给出“为何可比”（产品线、客户、技术节点、环节位置）和“哪些不可比”（6 月财年 vs 12 月、US GAAP vs CAS、USD vs CNY、代工模式、多元业务）。代码统一 TTM（按真实区间对单季度求和）、按中间价折算币种（标注汇率日期），每一步都能展开查看。
- **传导**：四类变量：①云厂商季度 Capex（iFinD 公司财务）；②美国管制和关税事件（资讯时间轴）；③海关 85177950 光模块月度出口、激光器出口（作为量价代理）；④美元兑人民币中间价。路径是“变量 → 环节 → 公司业务（如境外收入 90.58%）→ 指标（营收、毛利率）”。选中一个事件，就能看到受影响的公司，并跳到对应的历史序列对照（如 Meta Capex vs 中际旭创单季营收）。只展示历史共变和静态敏感性，不做预测。

## 5. 系统架构与部署

```
本地 Python 管道（iFinD 密钥只留在本机）
  ingest（限频 / 429 重试 / 请求哈希缓存）→ parse（表格解析、单位和财年映射、恒等式校验）
  → extract（LLM 抽取 + 片段校验）→ grade（规则）→ build（snapshot_vN.json + diff）
        ↓ wrangler pages deploy
Cloudflare Pages 静态站（React + Vite）+ Pages Function `/api/ask`
  （先过合规拦截器，再在快照证据上检索后由 LLM 作答；检索不到就说不知道）
```

“持续可更新”的实现方式：Windows 计划任务每天跑一次管道，然后自动部署。iFinD 在海外 CI 机器上能否调用尚未验证，所以不放在 GitHub Actions 上，README 里会如实说明。SEC EDGAR 作为海外数字的第二来源；扶摇接入后作为 A 股数字的第二来源。
