除高频行情外都是**自然语言 query**：服务端先把问句解析成指标，再取数。返回大多是 Markdown 表格，外加一份 `indicators_params`（解析出的指标、报告期、单位）。这对证据链有利：每个数字都能落到“字段名 + 报告期参数 + 调用记录”。缺点是解析结果会漂移（见第 4 节）。

## 4. 关键陷阱（要写进解析层和测试）

### 4.1 自然语言解析漂移
同一个意图，换个问法结果就不同：s04 和 s16 同样问半年报分产品，一次失败一次成功；s07 用区间问法失败，s17 逐个写日期成功；g08 问“最新”失败，g09 写明季度成功。
**对策**：每类数据只用经过验证的**固定问句模板**；拿到结果后做列名校验，缺少预期列就换备用模板重试，仍然失败就记为“缺失”，绝不让 LLM 去补数。

### 4.3 字段语义与单位
- “项目毛利”实际是毛利**占比**（%），不是金额（s03 元数据 `数据类型: 占比`）。
- 港美股、指数的表头一律写“单位：元”，实际是美元或点数。币种以 `报表币种` / `交易币种` 字段为准。
- 数值有“417.7786亿”“1.5693万亿”“7.904245614275E11”三种写法，空值有 `\t`、`null`、空串三种。
- 单季度数据的元数据“季度: 第一季度”不可信，以行里的日期为准。
**对策**：统一的 normalizer + 单元测试；做恒等式校验（各季度累加 = 累计值；分产品合计 = 营业收入，s03 合计 382.40 亿 = s05 营收 382.3994 亿 ✅）。

### 4.4 行情的非交易日填充
s09、g05、i01 都含周末和节假日行，收盘价沿用前值。**对策**：涨跌幅为空即视为非交易日，剔除。

### 4.5 两源冲突（同一来源的不同接口）
总市值：日频接口 7904.2456 亿（s08） vs 实时接口 789,199,459,470（s10），差 0.15%。**对策**：以日频收盘为主口径，冲突写进 conflict 记录并在页面上展示。

### 4.6 限频
- 并发 6 个实时请求：1 个成功，**5 个 429**（`burst_6.json`）。
- **429 被包在 `ok: true` 的 content 文本里**（`call failed, status: 429 …请求过于频繁`），不会抛异常。
**对策**：客户端检测文本中的 `status: 429`，串行调用、间隔 ≥700ms，指数退避重试 3 次；全量刷新约 300 次调用，按每次约 3s 估算需 15–20 分钟。免费版的**调用次数额度未知**，所有调用按请求哈希缓存，增量更新。

### 4.7 证据可链接性
- 公告：只有标题和日期，**没有 URL**。用标题拼巨潮全文检索链接，同时保留 iFinD 调用记录（probe_id、参数、时间）作为可回放证据。
- 新闻、研报转载：有 URL，但多为微信、雪球等第三方；只展示标题、日期、链接和 ≤100 字摘要。
- 互动易：只能拿到 iFinD 概念解析或媒体转述里的二手文本，来源类型要如实标注“iFinD 概念解析（引互动易 2024-01-22）”。

## 5. 对产业方向的判断

**保留“AI 算力光互联”，不换方向。** 理由：

1. A 级证据的核心数据（分产品收入）已经实测：中际旭创、新易盛、天孚、源杰、中瓷都有，而且能拿到毛利率。
2. 概念可信度分级的原料很足。CPO 概念 225 只成分股，每只都有带来源和日期的概念解析，从“年报有收入”到“互动易口头表态”都有真实样本，s13 还有算法误报样本。
3. 传导链的四类变量都有数据：Capex（Meta 等季度现金流）、政策（新闻事件时间轴）、出口量价（海关 85177950 月度）、汇率（中间价）。只有光芯片价格缺失，需要降级（见风险清单）。
4. 跨市场可比的核心陷阱（财年错位、币种、准则）已经实测并有对策，正好是展示专业度的地方。
